01 — 呼出

碰一下就出来，不抢焦点

面板用 .nonactivatingPanel 实现，呼出后你的当前窗口仍是前台。 不用点两下，不用切应用——指针碰边缘，面板就位，光标已经在编辑器里。

⌥⌘N呼出 / 收起
02 — 写

是一个真编辑器，不是便签框

标题、列表、任务、代码块、引用、表格、行内代码、链接、高亮、颜色。 工具栏解决「先选格式再打字」，选中气泡解决「先选文字再改格式」——两条路径都不绕。

悬停段落左侧出现手柄，可拖拽重排
03 — 找

⌘K 一个入口，够用到底

新建、切换列表、搜索、调透明度、收起面板——全部收在一个命令面板里。 手不离键盘就能完成所有操作。

⌘K命令面板
04 — 找回

记不住关键词，也能搜到

基于 macOS 原生 NLEmbedding 的 300 维向量索引， 完全脱机、零模型体积。关键词稀疏匹配 + 向量余弦相似度混合排序， 用一句自然语言就能找回你写过的东西。

⌘F搜索笔记内容
为什么不是又一个笔记应用

这个品类被锁在 Apple 生态里太久了

成熟的屏幕边缘笔记已经有几款，但它们都只服务 Mac。同时检索能力普遍停在「关键词 + 标签」—— 笔记越记越多，越找越难。iFolo 想做三件它们结构性做不到的事。

01

跨平台

外壳原生、编辑器在 Web 层。同一套编辑器代码直接复用到 Windows 外壳，不必重写两遍。Mac 和 Windows 用同一份笔记。

原生外壳 + Web 编辑器
02

同步不设体积上限

附件走独立通道，正文才进同步日志。一条带十几张截图的笔记，不会因为「太大」被静默跳过同步。

附件与正文分离
03

语义检索

用一句自然语言找回你写过的东西，而不必记得当时用了哪个词。索引全在本机，完全脱机。

300 维 · 本地向量
