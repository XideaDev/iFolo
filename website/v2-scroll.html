四个环节

呼出、写、找、找回

从「想到一件事」到「把它记下来」，中间不该有摩擦。下面四张图是真实界面， 放大到你平时看不清的地方。

01 — 呼出

面板出来，你的窗口还在前台

用 .nonactivatingPanel 实现。面板显示的同时， 当前应用仍是前台应用——光标已经在编辑器里等着，不需要先点一下面板。

  • 指针移到屏幕右边缘，停留 120ms 即呼出
  • 3pt 热区宽度，是「能碰到」与「不误触」的平衡点
  • 也可以按 ⌥⌘N 随时呼出
顶栏 · 36px
02 — 写

工具栏和选中气泡，分工不同

工具栏解决「先选格式再打字」，选中气泡解决「先选文字再改格式」。 只做其中一个，都会让一半的操作路径变长。

  • 段落类型、B / I / U / S、行内代码常驻一行
  • 链接、文字颜色、高亮、Emoji 收在右侧
  • 窄面板放不下时收进「⋯」，不横向滚动
富文本工具栏 · 34px
03 — 推进

待办不是勾选框，是六个状态

一条待办可以处在「待办池 / 待办 / 进行中 / 审核中 / 已完成 / 已取消」， 归入五个分组。点一下胶囊就推进到下一个状态，不用打开任何面板。

  • 状态名、颜色、图标都可自定义
  • 可设置「淡化该行」「加删除线」
  • 状态以 - [inProgress] 写进 Markdown，别的编辑器也读得懂
任务状态胶囊
04 — 找

⌘K 一个入口，够用到底

新建、切换列表、搜索、调透明度、收起面板——全部收在一个命令面板里。 键盘不打滑，鼠标不用找。

  • 直接在面板里输入就能搜笔记
  • 每条命令都标了快捷键，顺手就学会了
  • Esc 关闭，⌘L 直接回列表
命令面板 · ⌘K
05 — 找回

记不住关键词，也搜得到

基于 macOS 原生 NLEmbedding 的 300 维向量索引， 完全脱机、零模型体积、不联网。关键词稀疏匹配 + 向量余弦相似度混合排序。

  • 用一句自然语言描述你记得的意思
  • 索引在本地构建，笔记不出设备
  • 可按「全部 / 含待办 / 纯笔记」筛选
语义检索

设计体系

配色不是挑出来的，是从 logo 里长出来的

logo 本身是橙、蓝、绿三原色的几何构成。整套界面色板全部由它派生， 不引入任何外部流行色，不用渐变，不用发光。

iFolo Blue
#5CA3FF
主色 · 品牌识别与填充
白底 2.58:1，不承载文字
iFolo Green
#69CF3D
辅助色 · 完成与成功
语义专用，不做装饰
iFolo Orange
#FFA51F
强调色 · 提醒与待办
同屏面积不超过 10%

四个色族、44 个色阶、含深色模式，全部通过 WCAG 2.1 对比度校验。可读文字统一走 700/800 深档 —— 品牌标准色对比度只有 2.58，只做填充。
